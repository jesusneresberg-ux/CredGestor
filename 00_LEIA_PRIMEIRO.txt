📱 GERAR APK ANDROID
════════════════════════════════════════════════════════════════════════════════

Para criar o APK instalável:

1. Leia: INSTALACAO_RAPIDA.md (guia completo passo a passo)

2. Resumo rápido:
   - Instalar Node.js + JDK 17 + Android SDK
   - npm install && npx cap add android
   - Copiar arquivos Android
   - Criar keystore
   - ./gradlew assembleRelease

3. Tempo: 10-15 minutos (primeira vez)

4. Resultado: APK em android/app/build/outputs/apk/release/
